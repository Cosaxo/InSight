# The genetic axiom — current theory

*Regenerated from `graph.json` by each run; the graph is the data, this
page is its readable face. Last regenerated 2026-08-25 (first scheduled
run). Statuses follow CHARTER §4: conjecture → argued → cited →
measured; sources live on the nodes.*

The perfect genetic axiom, as the graph currently stands: **import,
never assay; keep the file with the person; and point everything at the
one asymmetry that matters — the phenotype battery is the scarce asset,
and the genome is a weak, fixed prior beside it.**

## Entry — the import door (gen-1 · argued, gen-8 · cited)

The axiom imports molecular files people already hold; it never touches
a sample or a lab (**gen-1**). That was first argued for consumer
genotype files (23andMe/AncestryDNA class). This run generalized it
(**gen-8**): the same logic — stay on the analysis side, import what
consented people already hold — covers **consumer methylation files**,
and the aging half of the theory needs it to. The enabling premise is
peer-reviewed: consumer-platform methylation cohorts are
publication-grade (a TruDiagnostic cohort of n=14,213 is a validation
cohort in *Nature Aging*; the same platform ran a randomized twin trial
in *BMC Medicine*). Raw-file access for consumers is reported at vendor
grade only — confirming it is a named scout task. Because methylation is
a *state* where genotype is a *constant*, the perfect import is a
longitudinal series of files, as a property of what the system accepts —
per charter §9, never a suggestion that anyone test or intervene on a
schedule.

## Custody and consent (gen-2 · argued, gen-6 · argued)

The genome stays where the person is; only derived, banded quantities
travel (**gen-2**). Genetic data is never about one person, so consent
is familial-aware and participation itself is confidential (**gen-6**).
The adversarial check strengthened this axis this run: a methylation
array file is **also a genotype file at reduced density** — thousands of
SNPs are recoverable from EPIC data at >98% concordance, enough to
identify close relatives (MethylGenotyper, cited at gen-8) — so both
custody and familial consent apply to imported methylation files at
full strength, exactly as to genomes.

## The asset (gen-3 · argued)

The scarce asset is the phenotype battery, not the genotypes; the axiom
optimizes pairing quality (people with BOTH a scored file and a deep
phenotype record) over genotype count (**gen-3**). First external
support arrived this run: in Framingham, educational mobility predicts
DunedinPACE pace-of-aging and mortality, holding under within-family
sibling fixed effects — behavioral phenotype carrying aging signal that
shared family background does not explain. A future run may raise this
node after full-text verification.

## Aging (gen-4 · cited, gen-7 · cited)

The run's main advance. Two claims, now cited:

- **The boundary (gen-7):** a SNP genotype file carries a *prior* on
  aging, never a *measurement* of it. Every epigenetic clock (Horvath,
  Hannum, PhenoAge, GrimAge, DunedinPACE) reads CpG methylation from a
  dedicated array; the newest strong measures read plasma proteomics
  (age at r≈0.94 from ~200 proteins; organ-specific aging). A genotype
  call file has no methylation channel, and imputing methylation from
  mQTLs recovers only the genetic component (~0.20 average correlation)
  — a polygenic score wearing a clock's costume. The skeptic pass hunted
  for a counterexample and found none.
- **The ambition (gen-4):** aging work runs through
  behavior-by-aging-measure crosses over the phenotype battery.
  Genotype-side aging signal is honestly weak (APOE-dominated longevity
  GWAS; ~5-year lifespan gap between extreme PGS deciles as a
  population contrast; GWS instruments for clock acceleration at
  0.47–4.41% of variance — instrument strength, not a PGS ceiling —
  with GrimAge, the best mortality predictor, the least genetically
  instrumentable). The heritability ceiling of longevity is itself
  contested across a 5× range (<10% to ~50%), and heritability is not
  predictability from a common-SNP array in any branch of that dispute.
  Discovery GWAS runs at n≈300k–1M and stays out of scope. What IS
  established science is the cross: education, personality
  (conscientiousness) and psychosocioeconomic stress all track
  second/third-generation clock aging in large cohorts. The axiom's
  contribution to aging research is the deepest behavioral phenotype
  battery crossed with imported aging measurements and genotype priors
  — hypothesis generation over consented aggregates, never medical
  advice.
