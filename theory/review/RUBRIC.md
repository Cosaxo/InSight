# The rubric — v1 (2026-09-01)

The instrument the review lane scores with (CHARTER §12). Versioned:
a change here is a dated bump of the title, argued first in this
lane's `graph.json`, and every `scores.json` entry names the rubric
version it was scored under, so scores across a bump are never read
as one series without saying so.

**Six dimensions, each 0–10, each against the charter — never against
another lane.** A score is a reading of the contract: every dimension
below is a clause of `CHARTER.md` turned into a measure, and the
evidence line beside a score names what was counted. A number without
its evidence line is not a score.

| Dimension | The clause it measures | What is counted |
| --- | --- | --- |
| **Useful** | §1 — the axiom's purpose is to create data and data-connections as powerful and useful as possible, or to make another axiom's data stronger | Claims that name a coupling with the instrument that would test it; `REQUESTS.md` rows that say what they would make measurable; verdicts earned (worth-building > not-yet > none); anything a product decision could act on |
| **Innovative** | §1 — the perfect system, designed as if practicality did not exist | Claims that go beyond the default of the sources they cite; new couplings, instruments or candidate axioms; a contradiction opened against a sibling on evidence; the disregard-practicality licence USED rather than the buildable restated |
| **Effective** | §3 — the ratchet: every run moves a status, adds a claim, or merges/prunes | Statuses moved per run since the last review; contradictions resolved by revision; prunes with a trace; fission that conserved argument rather than words; Lakatos' test — a lane that names falsifiers and predicts is progressive, one that only accommodates is degenerating even while its node count grows |
| **Rigorous** | §4 and §9 — the ladder rises only on the evidence that defines the rung; no invented source, number or result | The spot-check: at least two `cited` sources per lane among nodes risen or added since the last review, fetched and read — real, and saying what the node claims; statuses that match their evidence; falsifiers named; the adversarial pass recorded in the LOG row |
| **Connected** | §1 — cross-axis connection is first-class subject matter, never an appendix | Cross-graph edges added and resolving; central's `QUESTIONS.md` items answered and marked; a sibling's result consumed; stale sibling references flagged for their owners |
| **Legible** | §6 — written for a person with five minutes | `THEORY.md` regenerated and readable as the graph's face; nodes within the 400-word budget (go-7); a LOG row that says what moved in one line; a request a person could carry |

## Anchors

The scale is the same for every dimension. Between anchors, the
nearer one; when in doubt, the lower one — the ladder's own rule.

| Score | Means |
| --- | --- |
| 0 | Nothing landed since the last review (go-11's silence), or the dimension is absent from the work |
| 2 | Words moved and the dimension did not — growth without motion, the ratchet's named failure |
| 4 | The charter's minimum, met honestly: one real advance per run on this dimension |
| 6 | The advance is one another lane could use — an edge, an answered question, a request with its measurable named |
| 8 | Another lane DID use it (an edge from their side, a verdict, a digest item), or the work reached `measured` on InSight's own numbers |
| 10 | Reserved: the work changed what the product does or decides (a bridge crossing), or overturned a sibling claim by evidence |

## The unit

One review covers the runs since the previous review — at the
every-other-day cadence, one run per lane, sometimes none or two. A
lane with no run in the window scores 0 on Effective and keeps its
other scores from the last review, marked *carried*; the ledger says
which.

## Feedback

Per lane, per review, **at most three items**, each:

- actionable within ONE run (the ratchet's unit — "restructure your
  theory" is not an item; "fission rev-x's 900-word detail into the
  claim and its two consequences" is);
- naming the dimension it would move and the evidence that would show
  it moved;
- about HOW the lane works, not WHAT it should conclude — subject
  matter steering is central's (§6), and an item that strays into it
  is written as a suggestion the lane may decline.

The lane answers each item in its next LOG row — took it, or declined
it with a reason — and the next review scores the response: acted-on
feedback that moved the dimension is the closed loop; a decline with
a reason is a legitimate answer and is never marked down; a decline
without a reason, or silence, is scored as Effective's failure mode.

## What the reviewer may not do

Score itself; rank lanes as a verdict; rule on bridge requests; soften
a spot-check finding; invent motion in a quiet window. A review that
changes no score says so — that row is honest and cheap, and it is
what the owner's re-pacing dial reads.
