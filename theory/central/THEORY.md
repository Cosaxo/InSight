## The portfolio — which axioms carry the most value

**The metric (cen-2, argued — claim revised this run).** An axiom's
crowd value is the drop in held-out one-step-ahead predictive
log-loss on the other axioms' observations when its columns enter the
conditioning set — on a common population under explicit missingness,
never on per-pair intersections. The revision: the 08-28 form said
pairing governs precision, not definition — thin pairing widens error
bars, it does not zero value. pat-4 (cited this run, the
data-combination literature) shows that holds only ABOVE zero: two
axes never observed jointly on the same people pin their coupling to
a conditional Fréchet set under the declared anchors, and no crowd
size narrows it — so an axiom's crowd value is defined only over the
set of axes it is co-observed with, set-valued elsewhere; the first
paired person buys identification, every later one precision. The
claim string now carries the boundary, and the prose contradiction
pattern logged (go-6) is resolved by target revision. pat-12 (cited)
adds the constructive half: pairing is a design variable, and
co-service on the spine is what buys a model-free coupling. The
budget stays two-dimensional per pat-8 — persons fund crowd value,
the person's own occasions fund personal value — with cen-10 adding
a third dimension. que-8's conditional one-currency confirmation is
carried unchanged. Baseline term shipped (D325); path to `measured`
through the main-readable scorecard (ruled 08-28); the pairing count
it now needs is pattern's pairing ledger (ruled worth-building this
run).

**The third count (cen-10, argued — new this run).** tie-2 states
the observation: ties are a resource neither of pat-8's dimensions
names. This node supplies the argument and the consequence. The
relational axiom's unit is a tie (tie-1), and its readings decompose
— in Kenny's design tie-2 names — into perceiver, target and
relationship components that need each person to appear in several
dyads. So a pair with many days funds the within-tie estimand but no
person-level perceiver effect, and a person with many one-day ties
funds the perceiver and target effects but no within-tie dynamics:
pat-8's substitution failure one level up. Stated at its true
strength after the adversarial pass: the budget is two-dimensional
AT EACH UNIT, and the relational axiom introduces a second unit — so
the portfolio's bookkeeping needs a third count, a person's ties,
that no count of persons and no count of one person's days supplies;
the edge to pat-8 is typed refines for that reason. Consequences: an
axiom is placed in the portfolio by which resource funds its
DISTINCTIVE value (persons — genetic, interests-as-inventory;
occasions — body, time-use; ties — the relational axiom alone); for
a tie-unit axis the pairing count is of PAIRS (pat-4 transposed); and
who duels whom is a design variable — planned missingness on the tie
matrix (pat-12 transposed). Falsifiers: tie-1's own (relationship
variance negligible collapses the tie to the person and this count
to the first), or a result that days substitute for ties.
