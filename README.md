# Axiom Theory

A theory workspace on an orphan branch of Cosaxo/InSight — no product
code lives here, and nothing here changes the product except through
the bridge. **`CHARTER.md` is the contract**; `graph/SCHEMA.md` is the
claims-graph format; `theory/<lane>/` are the eight workspaces;
`DIGEST.md` is what the owner reads. The product's own docs are on
`main` (`docs/AXIOM-THEORY.md` there is the other half of the bridge).
